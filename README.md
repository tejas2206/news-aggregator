# News Aggregation System (Client–Server Application) 
*Technologies / Tools: Python, Flask, MySQL, curl, JSON, Git, SMTP*

• Designed and implemented a client–server architecture for real-time news aggregation, integrating 
multiple external APIs (NewsAPI, TheNewsAPI) using flask for RESTful communication. 

• Developed role-based authentication and access control (Admin/User) with secure login, user 
registration, saved articles management, and keyword-based notifications. 

• Built an Admin dashboard to manage API keys, monitor API status, moderate flagged content, and 
enforce keyword/category-based content restrictions. 

• Integrated MySQL database using MySQL Connector for efficient storage and retrieval of user accounts, 
saved news and categorized articles. 

• Implemented a robust scheduling system for periodic news fetching and automated notification delivery 
via email alerts, configurable at the user level.
